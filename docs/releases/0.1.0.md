# BeamNg.weather 0.1.0 alpha 1

Initial experimental release for in-game testing on BeamNG.drive 0.40.x.
For the English interface, use [0.2.1 or newer](https://github.com/hashk014/BeamNg.weather/releases).

- Automatic visual rain after loading a map.
- Optional BeamNg.weather panel with enable/stop, intensity, three quality
  levels and collision controls.
- Settings persist between sessions.
- Temporary effects use native game resources without replacing maps.

**Install:** put `beamng_weather_hashk014.zip`, without extracting it, in the
active user folder's `mods` directory. Restart the game, enable the mod and
load a Freeroam map. Add the optional panel through the UI Apps layout editor.

APIs and resources were inspected in game version 0.40.1.0. LuaJIT logic with
a mocked engine, the UI bridge and archive integrity were checked.
**In-game rendering and compatibility require confirmation by the tester.**
This version does not add wet roads, grip changes, audio or windshield effects.

GitHub's automatic **Source code** ZIP is not the installable mod package.
