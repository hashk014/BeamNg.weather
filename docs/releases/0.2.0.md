# BeamNg.weather 0.2.0 alpha 1

Reworked atmospheric rain and a full control panel for BeamNG.drive 0.40.x.
For the English interface, use [0.2.1 or newer](https://github.com/hashk014/BeamNg.weather/releases).

- Three rain volumes with different droplet sizes, speeds and viewing distances.
- Original textures: 16 variants per layer, tapered opacity and mipmaps.
- Five presets: Drizzle, Light rain, Shower, Downpour and Squall.
- Three custom presets saved between sessions.
- Eight controls: intensity, size, fall speed, turbulence, density variation,
  visibility, coverage and intensity transitions.
- Four particle budgets from 2,400 to 20,000.
- Options for collisions, existing map wind and sky lighting.
- Settings from version 0.1 remain compatible.

No windshield effects, puddles, friction changes, wet materials or rain audio.

**Install:** replace `beamng_weather_hashk014.zip` in the active user folder's
`mods` directory without extracting it, then restart the game. Add the panel
through **UI Apps > Add app > BeamNg.weather**. Resize an older panel or remove
and add it again if necessary. Scroll to access custom preset slots.

**Validation:** 18 mock-engine tests, Node UI bridge checks, textures and ZIP
integrity passed. The panel was tested with AngularJS 1.5.8 and simulated
game state. **In-game rendering and performance require confirmation.**
This experimental release does not promise physical or optical rain simulation.

GitHub's automatic **Source code** ZIP is not the installable mod package.
